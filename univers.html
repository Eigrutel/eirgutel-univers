    Objectif

    Univers sert à structurer un monde cohérent : lieux, peuples, règles sociales, croyances, pouvoirs, ressources, techniques, histoire et personnages. L’application aide à passer d’une accumulation d’idées à un système lisible, où chaque élément peut être relié, développé, déplacé et relu dans son contexte.

    Principe

    La vue générale donne la carte du monde. Chaque carte peut ouvrir une mindmap dédiée. On peut ainsi séparer les grands domaines sans perdre les liens entre eux : un royaume peut dépendre d’une ressource, une religion d’un mythe, un personnage d’un lieu ou d’un conflit.

    Fonctionnement

    • + Carte ajoute une nouvelle mindmap dans la vue générale.
    • + Élément ajoute une fiche dans la carte ouverte.
    • + Suite crée une branche depuis l’élément sélectionné.
    • + Lien relie deux éléments sans les placer dans la même branche.
    • Les exports PDF et le diaporama permettent de relire le monde comme un document de travail.

    Méthode

    • Commencer par la vue générale.
    • Créer les grands domaines du monde.
    • Développer chaque domaine dans sa mindmap.
    • Relier seulement ensuite les éléments entre cartes.
    • Relire avec le diaporama ou le livre-monde.

    Images

    Les images ajoutées depuis un fichier sont intégrées dans les données de l’univers. C’est pratique pour conserver un document autonome, mais cela peut alourdir le JSON et les exports. Les images par URL restent plus légères, mais dépendent de leur adresse d’origine.
